# 전후 예시

실제 사례를 일반화했다. 기밀 내용은 뺐다.

## 판정과 명령을 부탁으로

전:
```
확인했습니다. 항 구성은 맞습니다. 다섯째 항의 변수는 x 대신 y로 바꿔 주세요. 본문 [155]의 표기도 함께 고쳐 주세요.
```
후:
```
항 구성 확인했습니다. 다섯째 항의 변수는 x 대신 y(이진 변수)로 변경 부탁드립니다.
x(연속 변수)에 곱하면 x가 커질수록 목적함수가 작아져 의도와 다른 해가 나옵니다.
본문의 '(해당 문장 인용)' 문장의 표기도 함께 변경 부탁드리겠습니다.
```

## 조각 문장을 완전한 문장으로

전:
```
보완 가능. 보상 r = w1(지표 A) + w2(지표 B) + w3(지표 C), w1+w2+w3 = 1. 탐색은 방식 A 또는 B. 미구현이므로 '일 실시예에서' 수준으로.
```
후:
```
다음 내용으로 보완 가능합니다.
보상 r = w1(지표 A) + w2(지표 B) + w3(지표 C)이고, w1 + w2 + w3 = 1입니다.
탐색 정책은 방식 A 또는 B입니다.
아직 구현 전이므로 '일 실시예에서' 수준으로 기재 부탁드립니다.
```

## 의뢰인 틀의 총평을 전문가용으로

전:
```
1. 검토 항목 1: 일부만 커버됩니다. ...
2. 정합성: ...
3. 빨간 글씨: 6곳 모두 답했습니다.
4. 명칭: ...
```
후:
```
검토 의견입니다.
빨간 글씨 6곳은 각 위치에 댓글로 답했습니다. 그 외 댓글은 청구항 구조에 대한 의견과 질문입니다.

수정 검토 요청
1. 청구항 N의 필수 구성 완화. 이 구성이 종속항 전체를 묶습니다(청구항 N 댓글).
2. ...

확인 질문
가. 원출원 청구항 일부가 초안에 없는데 의도하신 것인가요?
나. 우선권 기한과 심사 상태에 따라 절차가 달라지는지 알려 주시면 감사하겠습니다.
```

## 결정 사항의 경계

전:
```
청구항 N과 M은 삭제합니다.
```
후:
```
청구항 N과 M을 방어용으로 남길지는 출원인이 확정해 회신드리겠습니다.
```
